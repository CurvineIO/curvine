# Adopter Logo Assets

Logos of organizations listed in [ADOPTERS.md](../ADOPTERS.md) are stored in this directory.

## Conventions

- One file per organization, named in kebab-case: `docs/adopters/<org-name>.svg` (or `.png`)
- SVG preferred; transparent PNG acceptable, minimum 240px wide
- Keep file size under 100 KB
- Reference in ADOPTERS.md with `height="40"` so rows stay visually consistent:

```markdown
| ExampleCorp | <img src="docs/adopters/examplecorp.svg" alt="ExampleCorp" height="40"> | ExampleCorp uses Curvine for ... |
```

## Permission

By submitting a logo, the contributor confirms they are authorized to grant the
Curvine project permission to display it in the repository, documentation, and
the project website (https://curvineio.github.io).
