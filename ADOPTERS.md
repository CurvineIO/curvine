# Who's using Curvine

Curvine is used by a growing range of companies and projects for AI-native and cloud-native file system workloads, from LLM training and AI Agent platforms to big-data analytics and multimodal data lakes.

If you are using Curvine and your name is not on this list, please send us a PR!

## How to add your organization

1. Fork this repository and add a row to one of the tables below.
2. Optionally include your logo: place an SVG (preferred) or transparent PNG under [`docs/adopters/`](docs/adopters/) named in kebab-case (e.g. `docs/adopters/examplecorp.svg`, < 100 KB), and reference it with `<img src="docs/adopters/examplecorp.svg" alt="YourName" height="40">`. By submitting a logo you confirm you are authorized to grant Curvine permission to display it in this repository and on the project website.
3. Open a pull request with the title `docs(adopters): add <your-org> to ADOPTERS.md`. One organization per PR, please.

If you prefer not to open a PR, you can also [open an issue](https://github.com/CurvineIO/curvine/issues/new) and a maintainer will add the entry for you.
